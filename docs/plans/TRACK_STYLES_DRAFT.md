# 工程轨道样式草案

此草案独立于轨道可见性与导出开关。样式快照、样式库联动及单句样式需要在上游 PR 324 的变更进入 2.0dev 后重新对照，消解重复实现并复验；PR 324 当前以 main 为目标，合入 main 本身不代表已进入 2.0dev。

Python 工程 ASS 渲染保留基线的主轨与启用叠加轨选择行为；副轨输出及轨道开关的组合需要与轨道功能集成后验证。

`tests/integration/track-style-a-integration.spec.mjs` 保留从整包提取的三个跨功能场景，尚未在独立草案中通过：

- 轨道创建撤销后，过期样式编辑目标不能修改样式库。
- 新建副轨和叠加轨时，样式快照与建轨操作作为同一撤销事务。
- 轨道预览开关隐藏相应贴图，同时保持导出不变。

这些场景依赖轨道开关与其界面入口，不在当前独立浏览器测试目录中执行；合并轨道能力后需运行并核对原断言。
