# 按影响选测：审阅与验证

范围：完整 `2.0dev 76bb330a` 上的选测、现有 CI 接线和结果核验。目标是让修改及其真实消费者得到可信反馈；未执行完整历史浏览器集合。本记录只描述本批工程证据。

## 审阅发现与处理

| 问题 | 处理与剩余保障 |
| --- | --- |
| 修改 Windows 构建脚本未触发打包；修改工作流未选中实际读取它的 Node 回归 | 将构建入口纳入预览影响，并合并工作流的真实引用消费者。打包和工作流变更有现仓正反例。 |
| 缩略图管理器经 Server 聚合边界传播后漏掉真实浏览器消费 | 补入缩略图领域，包括监听 `/api/thumbnails` 的 `filmstrip-real`。不扩大为所有应用浏览器。 |
| 普通文档、日志附件机械全量，或同名 README 夹具造成应用误选 | 文档消费者与源码消费者取并集；日志附件保留导航及真实读者。README 保留网站消费，不运行应用/媒体矩阵。 |
| 修改离线工具说明构建器未检查生成物新鲜度 | 选中对应文档检查和工具 Markdown 回归。 |
| 文件级 Python 严格执行混入私有素材与异平台用例 | 自动范围使用 `--automated`，逐项报告人工输入排除；异平台例外按精确 ID 和原因登记。缺依赖、真实失败及未知 skip 仍失败。显式人工组保留。 |
| 普通 push 丢失原有 Windows 调试 Python 覆盖 | Windows 仅补原有文档、发布、运行器及紧凑断言的所选交集。PR 使用既有 Windows Python 层，不重复执行该交集。原生命周期 Node 的平台覆盖按交集保留。 |
| Playwright 在 GitHub 实跑时增加运行元数据，导致发现与实跑误判为配置不一致 | 只忽略内建 `actualWorkers/ci/gitCommit/gitDiff` 元数据；其他自定义配置差异仍拒绝。使用真实 GitHub 环境变量的发现与实跑报告对照验证。 |
| 静态 portable skip 没有理由字段，旧模拟报告编造理由 | 删除一项已经停止支持的 `file://` 双页面预设冲突用例，并移除该精确豁免及独有导入。localhost 的预设保存、409 冲突和已保存内容保护继续验证。其他精确豁免不放宽。 |
| 本地浏览器先读取旧网站产物，或 release 只运行一个分片 | 网站消费者先构建输入；本地完整发布入口拒绝局部分片。CI 分片核对完整发现、配置、无重叠并集及实际结果。 |

## 验证范围

- 选测契约：真实直接/间接消费者、混合文档、删除、动态加载、多行/相对导入、解析异常、包清单基线、工作流及媒体准备。旧实现负对照不能通过新增选测契约。
- 执行与报告：选中目标真正进入命令、层级交集、同提交保存计划、网站顺序、发布分片限制、严格平台例外与人工排除。私有输入用例不再使自动组假失败；额外 skip 的负例仍失败。
- 浏览器：一份独立工具 spec 实跑 9 项通过；带 GitHub 环境变量的 localhost 预设冲突实跑 1 项通过。完整发现、分片结果及缺片/失败/不完整并集负例分别验证。
- CI：三个修改工作流通过 actionlint；原有相关工作流与发布说明契约通过。远端实际运行另按候选提交记录，本地结果不代替 GitHub 作业或人工验收。
- 文档检查在本地受保护稀疏检出中报告根 `AGENTS.md` 缺失，保留该错误；没有删除根文档要求来求通过。其余文档消费者、实际网站同步和远端结果分别核对。

本批没有实现通用文件级中断接续，也没有完成历史用例的系统清理。独立组继续执行与完整失败汇总按[测试治理原则](../../../engineering/TEST_GOVERNANCE.md)继续验收。
