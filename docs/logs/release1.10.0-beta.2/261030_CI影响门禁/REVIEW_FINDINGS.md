## A/D 保存与颜色多选复核

审查基线：`ebeed558` 后的本轮 diff；最终保存模块 SHA256 `8A5B0294AD74D38347A8B26BD02B6C97057A01900EF554305F89199DF9E7FF9E`。Terra 实现及验证，Sol 独立审查实际源码和回归；Astra 根据整理后的真实计时器证据、调用链和候选方案判断修复边界。

| 发现 | 处置与证据 |
| --- | --- |
| 只保护统一保存入口会漏掉定时备份。备份从 export-context 直接调用 `saveProjectToServer({ silent: true, backupOnly: true })`，仍会提交旧面板。 | 已修复：服务器、文件句柄的实际保存入口均在面板提交和序列化之前保护。备份遇未完成拖动只跳过本周期，保留原备份计时器，不安排普通自动保存。新增 VM 回归验证零面板提交、零构建、零请求及零普通保存调度。 |
| 取消或无位移释放不会重新提交 timing command，单纯丢弃到期保存可能延迟此前已完成编辑的落盘。 | 已处理：普通静默保存复用现有单个可重置防抖计时器；结束拖动后重新检查 dirty，自动保存关闭或目标解绑时按原规则停止。浏览器回归分别覆盖提交、取消与无位移释放。 |
| 手动保存及另存为需先完成原拖动事务。 | 已处理：复用当前 drag 的 pointerId 与最后指针位置调用既有 `endCueDrag`，同步刷新面板后再保存。验证真实 mouseup 不重复提交及一次 Undo 还原；不新增事务 API。 |
| 颜色多选夹具未建立独立颜色前提。 | 仅重建目标 case 的三条无色字幕，再真实着色一条；原筛选、多选、清除断言保留，新增颜色计数。Astra 复核无阻塞；不改产品颜色分组规则。 |

最终独立复核无未处置 blocker / major。已知边界：保护范围为现有字幕 waveform drag，不扩大到其他交互类型；正在拖动时跳过的自动备份等待原下一周期。自动化结果见[排查正文](浏览器失败排查.md)，维护者人工操作按[核验清单](波形保存与颜色筛选.checklist.md)另行确认，不能由只读审查或本地测试代替新 HEAD 完整 CI。
