## 当前事实与选择

common 采样首轮不是整体通过：临时计时入口缺少 Windows multiprocessing 的 main guard，子进程重新执行入口导致跨进程租约测试失败；已修复采样器，定向复核另记。另有新 main 的缩略图符号链接用例因本机权限 skip，required 正确阻断；不将其默认为成功，也不为本机改动平台例外。Linux CI 应真实运行该边界。最初直接调用 tsc 未提供项目配置，仅输出帮助而失败，随后按真实 `tsconfig.typecheck.json` 通过，未据此修改业务。

编辑器服务器原版独立 required 复核已通过 91 项、零 skip，内层 28.409 秒；原始报告与调用计数位于 `.artifacts/phase6-cost/`。同机独立结果与整组采样有波动，不据旧数值承诺固定比例。

## 实施与保留边界

只在 `LocalEditorServerTests` 类作用域缓存首次真实 `edit.build_editor_scripts()` 返回的不可变字符串。首次调用仍做真实校验和读取；后续每页仍执行服务器自己的 `ensure_bundle`，重新渲染实际模板、项目、配置与媒体路径。每例 HTTP 服务器、令牌、临时项目、设置、文件与线程继续隔离；没有共享可变页面或服务器，没有生产缓存，也不改变超时、poll、请求或原断言。类清理通过 `enterClassContext` 恢复原函数，单独跑方法仍调用真实构建入口。

前端构建/哈希/失效/冻结运行由原 `test_web_build`、manifest 与装配测试继续验证。本轮不删除测试，不替换真实 HTTP/Range/令牌/路径/保存覆盖，不降低 SQLite 持久化或真实媒体检查。
