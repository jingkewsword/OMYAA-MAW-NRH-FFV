## 像素扫描的等价边界

`boxes` 已先通过独立 Pillow 掩码得到非零包围盒。包围盒以外只有零值，不能影响色带或单行最大像素数，因此只缩小扫描行列范围；保留包围盒内所有空行间隔。阈值、全图掩码、峰值、字形哈希、原生/guard/viewport 三次真实 libass 渲染与所有 Canvas/逐帧比较不变，不导入 MAW 布局函数作为预期。

| 同一实际输入上的指标 | 原版 | 优化版 |
| --- | --- | --- |
| native/guard 帧 | 222 | 222，全部输出字段逐项相同 |
| 裁图调用（含字形裁图） | 654,784 | 32,988 |
| 裁图像素 | 1,070,023,584 | 16,582,464 |
| 指标函数累计单样本计时 | 22.298 秒 | 15.297 秒 |
| 完整 ASS 浏览器验收 | 36/36 | 同 36/36、同 ID/配置、零 skip/retry/flaky |
| 真实 FFmpeg 三种画布的像素 | 333 张 | 同 333 张，逐像素完全相同 |
| Playwright 整份墙钟 | 153.445 秒 | 184.700 秒；本轮不能宣称整份提速 |

两轮有其他工作负载，后轮还同时执行归属回归；不把局部计时减少强推成整份或 CI 关键路径收益，也不重跑挑选更好数字。除 `boxes` 外 7 个 oracle 函数 AST 保持相同，原 ASS 浏览器文件字节完全不变。

新增一个约 3ms 的独立 RGB 小样本检查，手工给出三轨包围盒、间断色带、负偏移、亮度/主导色阈值、峰值和字形像素，含空白角色/画面。旧/新版均通过；分别漏掉首行、末行的两个源码变体都由断言检出。它补充快速故障边界，不替代真实 FFmpeg 或浏览器检查。
